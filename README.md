# CivicTrack – AI-Powered Public Issue Tracking Platform

A full-stack public issue reporting and tracking platform designed to help citizens report civic problems, monitor complaint progress, and improve communication between the public and responsible authorities.

CivicTrack aims to make public issue management more transparent, accessible, and efficient through interactive maps, complaint management, and AI-powered assistance.

## 🎯 Key Features

### 🏙️ Public Issue Reporting

- Citizens can report public issues through the application.
- Submit complaints with relevant issue information.
- Organize and track reported public problems.
- Designed to improve communication between citizens and authorities.

### 📍 Interactive Map & Location Features

- Interactive map integration using Leaflet and OpenStreetMap.
- Location-based visualization of public issues.
- Map-based interface for understanding where issues are reported.
- Designed to make identifying nearby civic problems easier.

### 📋 Complaint Management System

- Public complaint feed.
- View reported issues.
- Filter complaints by type and status.
- Search functionality for finding specific complaints.
- Complaint status tracking.

### 🔐 User Authentication

- User registration and login.
- JWT-based authentication.
- Password hashing using bcrypt.
- Protected application functionality.

### 🤖 AI Assistant Integration

- CopilotKit integration.
- AI-assisted interaction within the application.
- Designed to improve user experience and simplify access to civic information.

### 🎨 Modern User Interface

- React-based frontend.
- Responsive application design.
- React Router for navigation.
- Axios for API communication.
- Lucide React icons.
